Graph Editor

Graph Editor is a browser-based graph editor for AtCoder and competitive programming. It helps you create directed graphs and undirected graphs, edit vertices and edges, arrange graph drawings, and export data for programming-contest input formats.

競技プログラミング向けのグラフ作成・可視化ツールです．ブラウザ上で頂点や辺を直感的に編集し，AtCoder などの問題で使いやすい辺リスト形式に変換できます．

Features

  • Create and edit directed and undirected graphs.
  • Move vertices and adjust graph layouts in the browser.
  • Switch between 0-indexed and 1-indexed vertex labels.
  • Export graphs as edge lists for competitive programming.
  • Save and restore graphs with JSON.
  • Export graph drawings as PNG or SVG images.

競プロ用グラフ作成ツールとしての使い方

  1. キャンバス上に頂点を追加します．
  2. 頂点同士を辺で接続し，有向グラフまたは無向グラフを作成します．
  3. 必要に応じて 0-indexed / 1-indexed を切り替えます．
  4. 作成したグラフを辺リスト，JSON，PNG，SVG として出力します．

グラフ理論のメモ，アルゴリズムの説明図，AtCoder などの入力例作成，テストケース作成の補助に利用できます．
